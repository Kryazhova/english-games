# Room Adventure — The Secret Room

A point-and-click English adventure: read the book, lift the cushion, collect a little key, unlock the drawer, reveal an invisible note with the lamp, solve a three-symbol chest lock and open the star door.

No movement controls, quiz rounds or scores. Items can be selected in the pocket or directly in object dialogs. Short English actions, optional Russian hints and a notebook support the learner. Progress uses secret-room-v1; restart affects only this adventure. Dependencies are validated when restoring progress.

Background: secret-room.webp. Built-in imagegen prompt: SECRET-ROOM-ART.md. Previous art remains preserved but is not loaded by this game.

Verified: out-of-order exploration, wrong items, key selection, cushion, drawer, note, lamp, wrong and correct codes, ending, restored progress, replay and invalid saved dependency recovery. Browser visual inspection was unavailable due to browser access policy.
